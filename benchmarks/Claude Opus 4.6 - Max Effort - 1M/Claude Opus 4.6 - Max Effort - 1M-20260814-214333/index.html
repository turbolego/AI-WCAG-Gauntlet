Overview

This document uses native HTML elements whenever possible. It avoids relying on color alone, preserves visible keyboard focus, and uses clear headings. A highlighted note can call out key ideas without conveying essential meaning by color alone.

An API can return a dated record. Authors may cite a reliable reference, quote it with clear context, and expand an unfamiliar definition at first use.

Text can be stylistically offset, idiomatic, annotated, no longer accurate, removed, or inserted. Chemical notation uses H2O, while powers use 23.
