Semantic structure

A page with clear relationships

Updated November 13, 2026

Semantic elements help people and assistive technology understand how information is organized. A clear structure supports navigation, while carefully chosen language makes each example useful.

Text and meaning

An ARIA attribute can supplement native HTML, but should not replace a suitable element. The accessible name is the name announced for an interface control.

Use bold styling for attention without implying importance, and savoir-faire for a phrase in another voice. A proper-name annotation can be underlined, and a highlighted phrase can identify a relevant result.

Examples include H2O, 2nd place, an outdated price, and a brief editorial note. A revision can show old wording alongside updated wording.

As Inclusive Components explains, good interface patterns account for different ways of browsing. One reader said, clear labels make complex forms easier to use.

Well-structured content helps every visitor find the information they need.

In a code example, press Tab to move focus; the output may say Focus moved to Search. A variable such as pageCount belongs in documentation.
