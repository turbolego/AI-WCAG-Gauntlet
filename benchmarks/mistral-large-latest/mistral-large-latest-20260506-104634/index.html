Text Formatting

This text demonstrates various text-level semantics:

  • Bold text using <b>
  • Strong importance using <strong>
  • Italic text using <i>
  • Emphasized text using <em>
  • Highlighted text using <mark>
  • Small text using <small>
  • Deleted text using <del>
  • Inserted text using <ins>
  • Subscript and superscript
  • Underlined text using <u>
  • Strikethrough text using <s>
  • Variable using <var>
  • Keyboard input using <kbd>
  • Sample output using <samp>
  • Code snippet using <code>
  • Bi-directional isolation using <bdi>
  • Right-to-left text using <bdo>
