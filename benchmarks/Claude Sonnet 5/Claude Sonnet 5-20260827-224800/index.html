    Details & Summary

    What is WCAG 2.2 Level AAA?

    WCAG 2.2 Level AAA is the highest level of web accessibility conformance. It requires all Level A, AA, and AAA success criteria to be met. AAA criteria include enhanced contrast ratios (7:1) and larger touch targets (44×44 px).

    Which HTML5 elements are required?

    The benchmark requires all 110 HTML5 elements from the WHATWG HTML Living Standard to be present at least once.
