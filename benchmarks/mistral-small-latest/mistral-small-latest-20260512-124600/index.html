Purpose of This Demo

This single-page application demonstrates HTML5 features with a strong focus on accessibility. It includes proper heading hierarchy, semantic markup, keyboard navigation, and contrast considerations.

Why Accessibility Matters

Web accessibility ensures that people with disabilities can perceive, understand, navigate, and interact with the web. This includes those using screen readers, keyboard navigation, or other assistive technologies.

Web accessibility means that websites, tools, and technologies are designed and developed so that people with disabilities can use them.

— W3C Web Accessibility Initiative

Document Structure

Proper document structure is fundamental for accessibility. Screen readers use heading levels to navigate content.

Semantic HTML Elements

Using semantic elements helps assistive technologies understand the page structure.

  • header - Contains introductory content
  • nav - Contains navigation links
  • main - Contains the main content
  • section - Contains thematic grouping of content
  • article - Contains self-contained composition
  • aside - Contains content tangentially related to the main content
  • footer - Contains footer content

Landmarks

Landmarks help users navigate pages more efficiently by providing a way to jump to specific sections.

  • <header role="banner"> - Site header
  • <nav role="navigation"> - Navigation
  • <main role="main"> - Main content
  • <aside role="complementary"> - Complementary content
  • <footer role="contentinfo"> - Footer

Contrast Metrics

Contrast ratios measure the difference in perceived brightness between two colors.

  • 4.5:1 - Minimum contrast for normal text (AA)
  • 7:1 - Enhanced contrast for normal text (AAA)
  • 3:1 - Minimum contrast for large text (AA)
  • 4.5:1 - Minimum contrast for large text (AAA)

Accessibility Checklist

Quick reference for accessibility best practices.

Keyboard Navigation

  • ✓ All interactive elements are keyboard accessible
  • ✓ Focus indicators are visible and clear
  • ✓ Tab order follows logical document structure
  • ✓ Skip links allow bypassing repetitive content

Semantic HTML

  • ✓ Proper heading hierarchy (h1 > h2 > h3, etc.)
  • ✓ Semantic elements used appropriately
  • ✓ ARIA roles used where needed
  • ✓ Landmarks properly defined

Forms

  • ✓ All form controls have associated labels
  • ✓ Required fields are clearly marked
  • ✓ Error messages are descriptive
  • ✓ Form controls have appropriate types

Media

  • ✓ Images have meaningful alt text or are decorative
  • ✓ Videos have captions and transcripts
  • ✓ Audio has transcripts
  • ✓ Color is not the only means of conveying information

Contrast

  • ✓ Text meets minimum contrast ratios
  • ✓ Interactive elements are clearly visible
  • ✓ Focus indicators are visible
  • ✓ Color combinations are tested
